# 📸 Vybe – Social Media Platform

Vybe is a **full-stack social media web application inspired by Instagram**, built using the **MERN stack**, allowing users to share posts, reels, and stories, interact through likes and comments, save content, and communicate via direct messaging.

---

## ✨ Features

- 🔐 User Authentication (Login & Signup)
- 🖼️ Image & 🎥 Video Posts
- 🎞️ Reels (Short-form Video Content)
- ⏳ Stories (Temporary Content)
- ❤️ Like & 💬 Comment System
- 🔖 Save / Bookmark Posts
- 💬 One-to-One Messaging
- 👤 User Profiles
- 👥 Follow / Unfollow Users
- 📱 Fully Responsive & Mobile-Friendly UI
- 🔒 Protected Routes using JWT

---

## 🛠 Tech Stack

### 🔹 Backend
- **Node.js**
- **Express.js** – API & route handling
- **MongoDB**
- **Mongoose** – Database connection & schema modeling
- **jsonwebtoken (JWT)** – Authentication
- **bcrypt.js** – Password encryption
- **dotenv** – Environment variables
- **cors** – Frontend–backend communication
- **cookie-parser** – Token storage
- **multer** – Image & video upload middleware
- **nodemon** – Development server auto-restart

---

### 🔹 Frontend
- **React.js**
- **React Router DOM** – Routing
- **Redux Toolkit** – Global state management
- **Redux / React-Redux**
- **Axios** – HTTP requests
- **React Icons** – UI icons
- **React Easy Crop** – Image cropping
